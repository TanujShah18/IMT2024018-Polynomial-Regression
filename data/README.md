# Data

This folder contains the four datasets provided for the assignment:

- `IMT2024018_train_var1.csv`
- `IMT2024018_test_var1.csv`
- `IMT2024018_train_var2.csv`
- `IMT2024018_test_var2.csv`

The training files are used for model fitting and 5-fold cross-validation. The test files are used only after model selection to generate the final predictions.
